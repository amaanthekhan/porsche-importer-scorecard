The problem

A sales table rewards the market, not the importer.

When regional volume falls for reasons no importer controls, a volume ranking punishes the wrong people. This scorecard measures five pillars against fixed targets, caps any single KPI at 110%, and keeps risk out of the points.

Pillars come from Porsche's published Importer of the Year criteria. The KPIs, targets and weights under them are my proposal.

    The method // Proposal

    Four steps. No black box.

    Every step is simple enough to explain to an importer's general manager in one minute. That is the test for a methodology that gets published.

    01 / Clean

    Check first

    Four data-quality rules run on every submission before anything is scored. Bad values are excluded, replaced with the importer's own mean of its other quarters, and logged.

    02 / Attain

    Against target

    Actual ÷ target where higher is better, target ÷ actual where lower is better. Capped at 110% so one outlier KPI cannot carry a pillar.

    03 / Weigh

    Five pillars

    Pillar score = weighted mean of its KPI attainments × 100. Total = pillars × weights 30, 20, 20, 15, 15. Weights are policy, so the stress test checks them.

    04 / Gate

    Risk lamps

    Financial, integrity and data-quality gates decide eligibility and never add points. Any red lamp removes an importer from the award ranking; its score is still shown.

    Choices I would put in front of the importers
    
      
    
        
    Targets, not peer rank, inside the score. An importer is measured against a fixed target, so one importer improving does not push another down. A cap at 110% rewards beating a target without letting one KPI dominate.
    
        
    Weights are policy, not maths, which is why the stress test exists. Four quarters averaged to soften one bad quarter; a rolling view is a better fit for in-year steering.

      Measures // measures.dax
      

      KPI Attainment =
VAR Actual = AVERAGE ( fact_kpi_quarterly[value_used] )
VAR Target = SELECTEDVALUE ( dim_kpi[target] )
VAR HigherBetter =
    SELECTEDVALUE ( dim_kpi[direction] ) = "higher is better"
RETURN
    MIN ( 1.1,
        IF ( HigherBetter,
            DIVIDE ( Actual, Target ),
            DIVIDE ( Target, Actual ) ) )

Pillar Score =
SUMX (
    VALUES ( dim_kpi[kpi_id] ),
    [KPI Attainment]
        * CALCULATE ( MAX ( dim_kpi[weight_in_pillar] ) )
) * 100

Total Score =
SUMX (
    VALUES ( dim_pillar[pillar_id] ),
    [Pillar Score]
        * CALCULATE ( MAX ( dim_pillar[base_weight] ) )
)

Eligible =
IF ( SELECTEDVALUE ( fact_risk_gates[gate_status] ) <> "RED", 1, 0 )

Rank (eligible) =
IF (
    [Eligible] = 1,
    RANKX ( FILTER ( ALL ( dim_importer ), [Eligible] = 1 ), [Total Score], , DESC )
)

Gap to Leader =
VAR LeaderScore = MAXX ( FILTER ( ALL ( dim_importer ), [Eligible] = 1 ), [Total Score] )
RETURN [Total Score] - LeaderScore

        2.
